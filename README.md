Dotfiles
========
Personal config files for Terminal, Emacs, etc.  Expects to be on local disk path `~/dotfiles/`.  Includes setup script to create symlinks from `~/dotfiles/` to expected config locations.

Emacs
------------
Check `user-init-file` variable contents with `C-h v`

  *  Expect OS X file to be `~/.emacs.d/init.el`
  *  Expect Ubuntu file to be `~/.emacs`
